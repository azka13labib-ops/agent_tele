# 1. Konsep Utama & Latar Belakang

nanoGPT adalah repositori buatan Andrej Karpathy yang merupakan rewrite dari [minGPT](https://github.com/karpathy/minGPT). Fokusnya bukan pada pendidikan, melainkan pada kepraktisan: "teeth over education". Artinya kode dibuat sereadable dan se-hackable mungkin, tetapi tetap fungsional untuk eksperimen nyata.

Beberapa poin latar belakang penting:

- Repo ini menyediakan implementasi GPT (decoder-only Transformer) murni PyTorch.
- `train.py` adalah training loop boilerplate sekitar 300 baris.
- `model.py` adalah definisi model GPT sekitar 300 baris.
- Bisa memuat checkpoint GPT-2 asli dari OpenAI untuk evaluasi atau finetuning.
- Versi terbaru yang direkomendasikan adalah **nanochat**, sedangkan nanoGPT dianggap legacy/deprecated, tetapi tetap dipertahankan sebagai referensi.

Dengan desain yang minimal ini, nanoGPT cocok untuk:
- Belajar bagaimana GPT dilatih dari nol.
- Fine-tuning model GPT-2 ke dataset kustom.
- Reproduksi eksperimen GPT-2 skala menengah.
- Dijadikan basis hack/eksperimen arsitektur.

# 2. Metode, Arsitektur, atau Alur Kerja Kunci

## Arsitektur Model

nanoGPT menggunakan arsitektur Transformer standar:

- Input token di-embedding ke dimensi `n_embd`.
- Terdapat `n_layer` blok Transformer.
- Setiap blok memiliki multi-head self-attention dengan `n_head` kepala.
- Context window / block size = `block_size`, yaitu jumlah token maksimum yang diproses sekaligus.
- Digunakan mekanisme masked attention agar model hanya melihat token sebelumnya.
- Output diproyeksikan menjadi logits kosakata, dan loss dihitung dengan cross-entropy.

Hyperparameter utama yang sering diubah:

| Parameter | Fungsi |
|---|---|
| `block_size` | Panjang konteks yang dipakai model |
| `n_layer` | Jumlah layer Transformer |
| `n_head` | Jumlah head attention per layer |
| `n_embd` | Dimensi embedding/feature |
| `batch_size` | Jumlah contoh per iterasi |
| `max_iters` | Total iterasi training |
| `dropout` | Regularisasi |
| `lr_decay_iters` | Titik decay learning rate |
| `compile` | Mengaktifkan PyTorch 2.0 `torch.compile()` |

## Alur Kerja Training

1. **Siapkan data**
   - Teks mentah diproses menjadi token id.
   - Untuk dataset karakter, gunakan `data/shakespeare_char/prepare.py`.
   - Untuk OpenAI BPE tokenizer, gunakan dataset seperti `data/shakespeare` atau `data/openwebtext`.
   - Output berupa `train.bin` dan `val.bin`, berisi token id mentah yang disimpan sebagai `uint16`.

2. **Atur konfigurasi**
   - Semua pengaturan ada di file config Python, contoh: `config/train_shakespeare_char.py`, `config/train_gpt2.py`, `config/finetune_shakespeare.py`.
   - Bisa juga di-override lewat argumen CLI.

3. **Jalankan training**
   - Single GPU: `python train.py config/train_shakespeare_char.py`.
   - Multi-GPU DDP: `torchrun --standalone
